I run personal and work Claude Code / Codex logins on one laptop. Both CLIs keep a single default state directory, so a work login is still there the next time I type `claude` in a personal repo.

ctxlane is a local Rust wrapper. Each profile gets its own vendor-state directory. A run clears the parent environment, sets `CLAUDE_CONFIG_DIR` or `CODEX_HOME`, and execs the official CLI. Same OS user. No proxy. Traffic still goes to Anthropic and OpenAI.

Install:

```
brew install mikigraf/tap/ctxlane
```

Repo: [github.com/mikigraf/ctxlane](https://github.com/mikigraf/ctxlane)

Isolation is env reconstruction plus a unique home, not a sandbox. Startup scans ancestor `.claude` / `.codex` files; an interactive Claude session can still walk into a descendant `.claude` later. Native macOS Keychain login switching is outside v0.2.0. Automated tests use fake vendor binaries, not live billing UI.

v0.2.0. Homebrew builds from the tagged tarball (`mikigraf/homebrew-tap`).
